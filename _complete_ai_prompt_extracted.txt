--- PAGE 1 ---\nComplete AI Prompt for a Fully Customizable Portfolio 
Website 
Create a modern, professional, high-performance personal portfolio website that can be hosted 
on GitHub Pages. The entire website must be fully customizable through an Admin Dashboard 
or CMS-style configuration system without modifying any source code. 
Main Goal 
The portfolio owner should be able to update every section of the website at any time through 
a visual interface or configuration panel. 
No coding knowledge should be required to update content. 
The website should be designed for software developers, university students, freelancers, 
designers, and IT professionals. 
 
Technical Requirements 
Hosting 
• Compatible with GitHub Pages 
• Static site generation preferred 
• SEO optimized 
• Fast loading speed 
• Mobile responsive 
• Progressive Web App (PWA) support 
• Dark and Light mode 
• Accessibility compliant 
Data Management 
All content should be editable through: 
• Admin Dashboard OR 
• JSON Configuration Files OR 
• Git-based CMS 
No source code editing should be required. \n\n--- PAGE 2 ---\nAll updates should instantly reflect on the website after publishing.
